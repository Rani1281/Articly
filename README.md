# Articly

This is a Flutter project built for Android, IOS, and Web

## What is this app?
- This app lets you save intresting articles for reading them later.
- Unlike Google Keep or similar apps, it allows you to set customisable reading reminders, keeps you on track on your progress and pushes you to achieve further 💪.

## Who is this app for?
- Anyone who likes to read for fun or for work.
- Busy people that don't have reading continuously.
- Anyone that wants to enrich their knowledge by reading.
- Researchers who need to conduct an analysis on multiple sources and need proper organization and management.
